# Schaltschrank – Home Assistant app repository

The Schaltschrank database (terminals, circuit breakers, RCDs, devices/channels, loads, overall graph) as an app
(add-on) for Home Assistant OS, including the mapping of KNX entities to their device, channel, terminal, circuit
breaker and RCD. The app's user interface is in German.

## Installation

1. In Home Assistant: **Settings → Apps → App store → ⋮ → Repositories**, add this address:
   `https://github.com/bytefactory73/ha-schaltschrank`
2. **Schaltschrank** appears in the app store → Install → Start, and switch on "Show in sidebar".
3. The data is loaded in the app via Einstellungen (settings) → "Datenbank importieren" (import database); see
   the app's documentation.

This repository contains the program only, no data.
